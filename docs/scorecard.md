# ScoreCraft scorecard

Will be generated by `cargo xtask scorecard` from `perf/budgets.toml`, `perf/baseline.json`,
corpus floors, `scorecard/*.toml` and the source tree (milestone M0). **Until then this page is
seeded by hand** with the budgets and areas the generator must report. Do not edit it by hand once
the generator exists: change the sources and regenerate (CI will run `cargo xtask scorecard --check`).
Checklist statuses are verified against the code; numbers here supersede estimates elsewhere.
