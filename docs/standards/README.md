# Standards

The Crafting Apps keep shared standards in a private repository (`craftrules`) that outside
contributors cannot read. ScoreCraft is independent, so the standards it relies on are written out
here, in our own words, as the binding versions for this repository.

| Standard | What it governs |
|---|---|
| [never-crash.md](never-crash.md) | No panics, no `unsafe`, hostile-input rules, last-resort guard |
| [progress-docs.md](progress-docs.md) | The status header, revision history and update rules for every progress doc |
| [fonts.md](fonts.md) | Where fonts come from, licences, how they are embedded |

Changes to a standard go through an [RFC](../../rfcs/0000-decision-process.md).
