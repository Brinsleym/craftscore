# ScoreCraft documentation

ScoreCraft is an open-source, clean-room reimplementation of the enScore sheet music reader,
written in pure Rust. This book collects the developer, architecture, format, automation and
security documentation. The working documents that change with every PR (feature map, parity,
gaps, roadmap) live in [`docs/`](https://github.com/Brinsleym/enscore-cleanroom/blob/main/docs) and are linked from here.

The project is **pre-alpha**: the process and design exist, the code does not yet. Pages describe
the design that milestone M0 onward must implement; each says so where behaviour is planned rather
than built.
