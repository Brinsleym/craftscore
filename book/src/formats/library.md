# The library format

A ScoreCraft library is a documented directory (`<Name>.scorecraft/`) of content-addressed blobs,
per-score JSON records and per-page annotation op logs, written atomically. It is readable without
ScoreCraft. Specification: [`docs/file-format-parity.md`](https://github.com/Brinsleym/enscore-cleanroom/blob/main/docs/file-format-parity.md#scorecraft-library-format).
